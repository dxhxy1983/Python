# 文件夹监控工具 - 开机自动监控配置指南

## 快速配置步骤

### 第一步: 添加监控路径
1. 点击"浏览..."选择要监控的文件夹
2. 点击"添加路径"
3. 可以添加多个文件夹

### 第二步: 设置自动开始监控
✓ 勾选 **"程序启动时自动开始监控"**
- 这样程序启动后会自动开始监控,无需手动点击

### 第三步: 设置开机自启动(可选)
✓ 勾选 **"开机自启动"**
- 程序会被添加到Windows启动项
- 开机时自动运行并开始监控

### 第四步: 保存配置
点击 **"保存设置"** 按钮
- 所有配置会被保存到配置文件
- 下次启动时自动加载

## 完整配置示例

```
监控路径: C:\Users\Documents\项目文件夹
         D:\Work\资料

监控事件: ✓ 新增  ✓ 删除  ✓ 修改

临时文件: ✓ 过滤临时文件

启动选项: ✓ 程序启动时自动开始监控
          ✓ 开机自启动

[保存设置]
```

## 使用场景

### 场景1: 开机自动监控
- 勾选"开机自启动"
- 勾选"程序启动时自动开始监控"
- 保存配置
- 效果: 每次开机程序自动运行并监控

### 场景2: 仅开机自动监控(不立即显示界面)
这个程序会显示界面窗口。如果需要在后台运行,
可以考虑使用系统的任务计划程序。

### 场景3: 手动启动监控
- 不勾选"程序启动时自动开始监控"
- 需要时手动点击"开始监控"

## 验证配置

配置完成后,可以:
1. 点击"开始监控"测试是否正常工作
2. 在目标文件夹创建/修改/删除文件
3. 观察日志区域是否有变化记录
4. 点击"保存设置"保存配置

## 取消开机自启动

1. 运行程序
2. 取消勾选"开机自启动"
3. 完成

## 注意事项

1. 监控路径必须存在,如果路径被删除会跳过监控
2. 程序会监控所有子文件夹
3. 临时文件(.tmp, .bak等)会自动过滤
4. 配置文件保存在程序同目录
